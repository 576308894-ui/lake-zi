# 风险管控需求说明书

---

## 一、功能概述

### 1.1 功能名称
风险管控

### 1.2 建设目标
对铁路工程项目施工过程中的各类风险进行标准化管理，通过风险库建立标准化风险模板，在项目风险管理中关联具体施工阶段和工点，实现风险的可追溯、可监控，确保施工安全。

### 1.3 使用角色
| 角色 | 职责 | 操作范围 |
|------|------|----------|
| 现场施工人员 | 查看风险信息、了解管控措施 | 查看风险数据 |
| 安全管理员 | 监控整体风险状况、落实管控措施 | 全部风险查看、措施落实跟踪 |
| 项目技术员 | 维护风险库、关联项目风险 | 风险库维护、项目风险关联 |
| 项目经理 | 掌控项目风险态势 | 查看统计概览 |
| 系统管理员 | 系统配置与权限管理 | 全部功能及权限配置 |

### 1.4 业务价值
- 风险库标准化管理，提升风险识别效率
- 项目风险关联施工阶段和工点，精准定位风险位置
- 大屏实时展示风险分布，可视化管理
- 责任人明确，责任可追溯

### 1.5 功能定位
本模块属于"安全管理"二级菜单，是智慧工地平台安全生产管理子系统的核心安全管理模块，与安全隐患、应急安全演练、安全红黑榜共同构成完整的安全管理体系。

## 二、业务流程设计

### 2.1 整体业务流程

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│ 风险库管理    │───→│ 项目风险关联  │───→│ 大屏展示      │───→│ 责任追溯      │
│(导入/新增)   │    │(从库选择)    │    │(风险分布)    │    │(责任人查看)  │
└──────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
         │                  │                      │
         ↓                  ↓                      ↓
    风险名称            施工阶段              风险点展示
    风险类型            单位工程/工点         管控措施展示
    风险等级            责任人信息            工点分布展示
    风险分析            大屏展示标记
    风险措施
```

### 2.2 业务输入
- 风险库数据（风险名称、类型、等级、分析、措施）
- 项目风险管理数据（施工阶段、适用范围、责任人）

### 2.3 业务处理
- 风险库管理：导入或新增标准化风险数据
- 项目风险管理：从风险库选择风险，关联施工阶段和工点，填写责任人
- 大屏展示：根据项目风险管理数据，展示各阶段、各工点的风险点和管控措施

### 2.4 业务输出
- 风险库列表
- 项目风险管理列表（关联施工阶段、工点、责任人）
- 大屏风险分布展示

## 三、功能详细设计

### 3.1 Tab切换

#### 3.1.1 功能说明
通过Tab切换风险库和项目风险管理两个模块。

#### 3.1.2 页面布局
- 顶部Tab栏：风险库、项目风险管理（默认选中）
- Tab激活状态：蓝色文字+蓝色下划线
- Tab未激活状态：灰色文字+透明下划线

2. 点击"查询"按钮执行搜索

## 五、业务规则说明

### 5.1 数据校验规则

| 规则编号 | 校验内容 | 校验规则 | 异常处理 |
|----------|----------|----------|----------|
| V-01 | 必填项校验 | 施工阶段、适用范围类型、适用对象、风险名称、责任部门、责任人必填 | 表单校验提示 |
| V-02 | 适用对象联动 | 选择"单位工程"时显示单位工程选项，选择"工点"时显示工点选项 | 动态加载选项 |
| V-03 | 适用对象至少一个 | 适用对象必须选择至少一个 | 表单校验提示 |
| V-04 | 风险名称必须选择 | 必须从风险库选择风险，不可手动输入 | 表单校验提示 |

### 5.2 风险库与项目风险管理关系规则

#### 5.2.1 从风险库选择规则
```
当从风险库选择风险时，自动填充以下字段（均为只读）：
- 风险名称（从风险库获取）
- 风险类型（从风险库获取）
- 风险等级（从风险库获取）
- 风险管控分析（从风险库获取）
- 风险措施（从风险库获取）
```

#### 5.2.2 风险信息只读规则
- 项目风险管理中的风险信息（名称、类型、等级、分析、措施）均为只读
- 不可在项目风险管理中修改风险信息
- 修改风险信息需在风险库中进行
- 修改风险库不影响已创建的项目风险管理记录

#### 5.2.3 风险库独立管理规则
- 风险库是标准化风险模板，不直接参与项目风险管控
- 项目风险管理是风险库在具体项目中的实例化应用
- 一个风险库风险可被多个项目风险管理引用

### 5.3 大屏展示规则

#### 5.3.1 大屏数据同步规则
| 同步条件 | 同步内容 | 说明 |
|----------|----------|------|
| bigscreen="是" | 风险数据 | 同步到大屏展示 |

#### 5.3.2 大屏展示内容
| 展示项 | 数据来源 |
|--------|----------|
| 施工阶段 | stage字段 |
| 工点/单位工程 | scopeObjects字段 |
| 风险名称 | name字段 |
| 风险等级 | level字段 |
| 风险管控分析 | analysis字段 |
| 风险措施 | measure字段 |
| 责任人 | person字段 |

#### 5.3.3 无预警规则
- 本模块不产生预警
- 仅展示风险分布和管控措施
- 预警功能由监测预警模块负责

### 5.4 责任人规则

#### 5.4.1 责任人记录规则
- 责任人仅用于记录和追溯
- 不参与业务流程流转
- 不触发通知或提醒

## 六、业务逻辑关联

### 6.1 主数据关系

```
风险库（1）─────→（N）项目风险管理
     │                      │
     │                      ↓
     │               大屏展示（数据同步）
```

### 6.2 父子级关系
| 父级 | 子级 | 关系说明 |
|------|------|----------|
| 风险库 | 项目风险管理 | 一个风险库风险可被多个项目风险管理引用 |

### 6.3 数据同步逻辑
| 同步方向 | 数据内容 | 同步方式 |
|----------|----------|----------|
| 风险库 → 项目风险管理 | 风险基础信息（只读） | 手动选择时填充 |
| 项目风险管理 → 大屏展示 | 风险数据 | bigscreen=true时同步 |

## 八、接口及数据交互

### 8.1 数据来源
| 数据 | 来源 | 获取方式 |
|------|------|----------|
| 项目风险管理数据 | 风险管控模块 | 接口查询 |
| 风险库数据 | 风险库模块 | 接口查询 |

| 单位工程数据 | 基础配置模块 | 接口关联查询 |
| 工点数据 | 基础配置模块 | 接口关联查询 |

### 8.2 接口调用关系

#### 8.2.1 项目风险管理列表查询接口
```
GET /api/risk/project-risks
参数:
  - stage: 施工阶段
  - name: 风险名称（模糊查询）
  - category: 风险类型
  - page: 页码
  - pageSize: 每页条数
返回:
  - 风险列表（含关联信息、责任人）
```

#### 8.2.2 项目风险管理维护接口
```
POST /api/risk/project-risks        # 新增
PUT /api/risk/project-risks/{id}    # 编辑
DELETE /api/risk/project-risks/{id} # 删除
```

#### 8.2.3 风险库列表查询接口
```
GET /api/risk/library
参数:
  - name: 风险名称（模糊查询）
  - category: 风险类型
  - level: 风险等级
  - page: 页码
  - pageSize: 每页条数
返回:
  - 风险库列表
```

#### 8.2.4 风险库维护接口
```
POST /api/risk/library        # 新增
PUT /api/risk/library/{id}    # 编辑
DELETE /api/risk/library/{id} # 删除
POST /api/risk/library/import # 导入
```

### 8.3 数据同步方式
| 同步场景 | 同步方式 | 说明 |
|----------|----------|------|
| 大屏数据同步 | HTTP轮询 | 大屏端定时拉取数据 |
