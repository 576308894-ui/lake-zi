# 沉降位移监测需求说明书

---

## 一、功能概述

### 1.1 功能名称
沉降位移监测

### 1.2 建设目标
对铁路工程施工区域周边地面沉降和水平位移进行实时监测，通过坐标对比计算偏差值，自动判断沉降和位移是否超限，保障施工安全，防止因沉降位移过大导致的地面塌陷、建筑物开裂等安全事故。

### 1.3 使用角色
| 角色 | 职责 | 操作范围 |
|------|------|----------|
| 现场施工人员 | 查看监测数据、处理异常预警 | 查看监测数据、处理异常 |
| 安全管理员 | 监控整体沉降位移安全状况 | 全部监测点查看、预警处理 |
| 项目技术员 | 配置监测点、维护偏差规则 | 监测点维护、规则配置 |
| 项目经理 | 掌控项目沉降位移态势 | 查看统计概览、异常处理审核 |
| 系统管理员 | 系统配置与权限管理 | 全部功能及权限配置 |

### 1.4 业务价值
- 实时掌握监测点沉降位移动态，降低地面塌陷风险
- 自动化预警机制，减少人工巡检成本
- 坐标对比分析，直观展示变化趋势
- 偏差规则灵活配置，适应不同监测标准

### 1.5 功能定位
本模块属于"监测管理"二级菜单，是智慧工地平台安全生产管理子系统的核心监测模块，与水位监测、抽水泵管理、基坑维护共同构成完整的基坑监测体系。

## 二、业务流程设计

### 2.1 整体业务流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  监测点配置 │───→│  数据采集   │───→│ 坐标对比   │───→│ 偏差计算   │───→│  状态判断  │
│ (新增/编辑) │    │ (传感器采集) │    │ (上期vs本期)│    │ (X/Y/Z差值)│    │ (自动)    │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └─────┬────┘
                                                                     │
                    ┌────────────────────────────────────────────────┤
                    │                                                │
              ┌─────▼─────┐                                  ┌─────▼─────┐
              │  正常状态   │                                  │  异常状态   │
              │ (持续监测)  │                                  │(预警/超限) │
              └───────────┘                                  └─────┬────┘
                                                                   │
                    ┌───────────────────────────────────────────────┤
                    │                                               │
              ┌─────▼─────┐                               ┌──────▼──────┐
              │  预警通知   │                               │  人工处理   │
              │ (自动触发)  │                               │ (填写记录)  │
              └───────────┘                               └──────┬──────┘
                                                                │
                                                         ┌─────▼─────┐
                                                         │  处理记录   │
                                                         │  归档      │
                                                         └───────────┘
```

### 2.2 业务输入
- 监测点基础配置数据（编号、名称、监测类型、所属基坑、安装日期）
- 上期监测数据（上期日期、上期高程）
- 本期监测数据（本期日期、本期高程）
- 偏差规则配置（X/Y/Z方向预警值、超限值、判断方式）

### 2.3 业务处理
- 坐标对比：计算本期与上期的高程差值
- 偏差计算：计算Y位移分量、X位移分量、累计沉降量、水平合位移
- 状态判断：根据偏差规则判断各方向状态（正常/预警/超限）
- 综合状态：取X、Y、Z三个方向中最严重的状态

### 2.4 业务输出
- 监测点数据对比表（上期/本期坐标、差值）
- 监测点详情（基本信息、监测数据）
- 偏差规则配置界面
- 预警通知（状态为预警或超限时）

## 五、业务规则说明

### 5.1 数据校验规则

| 规则编号 | 校验内容 | 校验规则 | 异常处理 |
|----------|----------|----------|----------|
| V-01 | 预警值与超限值关系 | 超限值必须大于预警值 | 保存时校验，提示"超限值必须大于预警值" |
| V-02 | 数值范围校验 | 预警值和超限值必须大于0 | 保存时校验，提示"必须大于0" |
| V-03 | 必填项校验 | 启用规则时所有阈值必填 | 表单校验提示 |
| V-04 | 日期格式校验 | 日期格式必须为YYYY/MM/DD | 输入校验提示 |

### 5.2 状态流转规则

#### 5.2.1 偏差状态判断规则
| 状态代码 | 状态名称 | 判断条件 | 颜色标识 |
|----------|----------|----------|----------|
| normal | 正常 | 绝对偏差 < 预警值 | 绿色 |
| warning | 预警 | 预警值 ≤ 绝对偏差 < 超限值 | 橙色 |
| overlimit | 超限 | 绝对偏差 ≥ 超限值 | 红色 |

#### 5.2.2 各方向阈值（默认值）
| 方向 | 预警值(mm) | 超限值(mm) |
|------|-----------|-----------|
| X方向位移 | 18 | 25 |
| Y方向位移 | 18 | 25 |
| Z方向沉降 | 15 | 20 |

#### 5.2.3 综合状态判断规则
```
综合状态 = MAX(X方向状态, Y方向状态, Z方向状态)
```
取X、Y、Z三个方向中最严重的状态作为综合状态：
- 超限 > 预警 > 正常

#### 5.2.4 Z方向判断方式
| 判断方式 | 说明 |
|----------|------|
| 按绝对偏差判断 | 取沉降量绝对值进行比较 |
| 区分沉降和隆起 | 分别设置沉降和隆起的阈值（当前版本未实现） |

### 5.3 偏差计算规则

#### 5.3.1 沉降量计算
```
zDiff = prevZ - currZ
```
- 正值表示沉降（高程下降）
- 负值表示隆起（高程上升）

#### 5.3.2 位移分量计算
```
yDiff = 本期Y坐标 - 上期Y坐标
xDiff = 本期X坐标 - 上期X坐标
```

#### 5.3.3 水平合位移计算
```
hDiff = √(yDiff² + xDiff²)
```

#### 5.3.4 单位换算
- 原始数据单位：米（m）
- 展示单位：毫米（mm）
- 换算规则：差值(m) × 1000 = 差值(mm)

### 5.4 自动触发规则
| 触发事件 | 触发条件 | 执行动作 |
|----------|----------|----------|
| 预警生成 | 综合状态变为预警或超限 | 推送预警到监测预警模块 |
| 规则重算 | 偏差规则变更 | 后台重新计算所有监测点状态 |

### 5.5 数据新增、修改、删除规则

| 操作 | 规则说明 |
|------|----------|
| 新增监测点 | 填写基础信息和初始坐标数据 |
| 编辑监测点 | 修改监测点信息，更新本期数据 |
| 删除监测点 | 删除监测点及关联的历史数据 |

## 六、业务逻辑关联

### 6.1 主数据关系

```
基坑维护（1）─────→（N）监测点配置（1）─────→（N）监测数据记录
     │                      │
     │                      ↓
     │               偏差规则配置（1）

### 6.2 父子级关系
| 父级 | 子级 | 关系说明 |
|------|------|----------|
| 基坑 | 监测点 | 一个基坑包含多个监测点 |
| 监测点 | 监测数据记录 | 一个监测点产生多条监测记录 |
| 项目 | 偏差规则 | 一个项目配置一套偏差规则 |

### 6.3 数据同步逻辑
| 同步方向 | 数据内容 | 同步方式 |
|----------|----------|----------|
| 传感器 → 监测点 | 本期坐标数据 | 传感器采集推送 |
| 偏差规则 → 监测点 | 阈值配置 | 规则变更时触发重算 |
| 监测点 → 监测预警 | 预警记录 | 状态变化时自动推送 |

  - code: 监测点编号（模糊查询）
  - prevDateStart: 上期开始日期
  - prevDateEnd: 上期结束日期
  - currDateStart: 本期开始日期
  - currDateEnd: 本期结束日期
  - page: 页码
  - pageSize: 每页条数
返回:
  - 监测点列表（含上期/本期坐标、差值、状态）
```

#### 8.2.2 监测点详情接口
```
GET /api/settlement/monitor-points/{id}
返回:
  - 监测点基础信息
  - 监测数据（上期/本期坐标、差值）
  - 状态信息
```

#### 8.2.3 监测点维护接口
```
POST /api/settlement/monitor-points        # 新增
PUT /api/settlement/monitor-points/{id}    # 编辑
DELETE /api/settlement/monitor-points/{id} # 删除
```

#### 8.2.4 偏差规则接口
```
GET /api/settlement/rules           # 查询规则
PUT /api/settlement/rules           # 更新规则
```

### 8.3 数据同步方式
| 同步场景 | 同步方式 | 说明 |
|----------|----------|------|
| 监测数据采集 | 定时轮询/传感器推送 | 按设定频率采集 |
| 状态计算 | 实时计算 | 数据更新后实时计算状态 |
| 预警推送 | 消息队列 | 状态变化时推送到监测预警模块 |
