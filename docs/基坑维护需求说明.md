# 基坑维护需求说明文档

## 1. 需求概述

### 1.1 需求背景
在铁路工程项目施工过程中，基坑监测是保障施工安全的重要环节。基坑维护模块用于管理基坑的基本信息和水位预警参数，为水位监测系统提供基础配置数据，确保基坑水位在安全范围内。

### 1.2 需求目标
- 实现基坑基本信息的增删改查管理
- 配置基坑的标准控制水位和报警水位参数
- 支持基坑与水井的关联管理
- 实现基坑数据的可视化展示

---

## 2. 功能需求

### 2.1 基坑列表

#### 2.1.1 页面布局
- 页面标题：基坑维护
- 新增按钮：右上角蓝色按钮，点击打开新增弹窗

#### 2.1.2 表格字段
| 序号 | 字段 | 说明 |
|------|------|------|
| 1 | 序号 | 自动编号 |
| 2 | 基坑编码 | 唯一标识，如 WP01 |
| 3 | 基坑名称 | 基坑的中文名称 |
| 4 | 标准控制水位（m） | 正常水位控制值，保留两位小数 |
| 5 | 报警水位（m） | 预警阈值，低于此值触发报警 |
| 6 | 操作 | 编辑、删除按钮 |

#### 2.1.3 操作功能
| 操作 | 说明 |
|------|------|
| 编辑 | 点击打开编辑弹窗，回填已有数据 |
| 删除 | 删除基坑记录，已关联水井的基坑不可删除 |

#### 2.1.4 删除约束
- 当基坑已关联水井时，删除按钮置灰并禁用
- 鼠标悬停显示提示："该基坑已关联N口水井，无法删除"

---

### 2.2 新增基坑

#### 2.2.1 弹窗表单
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 基坑编码 | 输入框 | 是 | 唯一标识，如 WP03，编辑时不可修改 |
| 基坑名称 | 输入框 | 是 | 中文名称 |
| 标准控制水位（m） | 数字输入框 | 否 | 保留两位小数，默认 0.00 |
| 报警水位（m） | 数字输入框 | 否 | 保留两位小数，默认 0.00 |

#### 2.2.2 表单校验
- 基坑编码：必填，格式校验（字母+数字），唯一性校验
- 基坑名称：必填，最大长度限制（如 50 字符）
- 水位数值：非负数字，支持两位小数

---

### 2.3 编辑基坑

#### 2.3.1 弹窗表单
- 表单字段与新增一致
- 基坑编码字段置灰，不可修改
- 回填当前基坑的所有数据

#### 2.3.2 保存逻辑
- 修改后的基坑名称、水位参数更新到数据库
- 不影响已关联的水井数据

---

### 2.4 基坑与水井关联

#### 2.4.1 关联规则
- 一个基坑可以关联多口水井
- 水井通过"基坑编码"字段关联到基坑
- 删除基坑前需检查是否有关联水井

#### 2.4.2 关联查询
- 实时统计每个基坑关联的水井数量
- 在删除操作时进行关联校验

---

## 3. 数据模型

### 3.1 基坑数据
```typescript
interface PitData {
  code: string;           // 基坑编码（唯一标识）
  name: string;           // 基坑名称
  controlWaterLevel: string;  // 标准控制水位（m）
  alarmWaterLevel: string;    // 报警水位（m）
}
```

### 3.2 水井数据（关联参考）
```typescript
interface WellData {
  code: string;           // 水井编码
  name: string;           // 水井名称
  workpoint: string;      // 关联基坑编码
  // ... 其他字段
}
```

## 4. 非功能需求

### 4.1 性能需求
- 基坑列表加载时间 ≤ 1秒
- 支持至少100个基坑数据的管理

### 4.2 可用性需求
- 删除操作需二次确认（待补充）
- 表单字段有明确的标签和占位提示
- 操作按钮有悬停效果和禁用状态提示

### 4.3 安全性需求
- 基坑编码唯一性校验，防止重复
- 删除操作需权限控制（待补充）

## 6. 交互设计

### 6.1 列表交互
- 鼠标悬停行高亮显示
- 操作按钮仅在悬停时显示（当前为常驻显示）
- 编辑按钮点击打开弹窗
- 删除按钮点击直接删除（待补充：二次确认）

### 6.2 弹窗交互
- 点击新增/编辑按钮打开弹窗
- 点击取消按钮关闭弹窗，不保存修改
- 点击保存按钮验证表单并保存数据

### 6.3 删除约束交互
- 已关联水井的基坑，删除按钮置灰
- 鼠标悬停显示tooltip提示

---

## 7. 关联模块

### 7.1 水位监测
- 水井配置时选择关联的基坑
- 水位监测数据关联到基坑
- 报警水位参数用于水位预警判断

### 7.2 监测管理菜单
- 基坑维护作为监测管理下的二级菜单
- 位于水位监测菜单上方
