# 抽水泵管理需求说明书

---

## 一、功能概述

### 1.1 功能名称
抽水泵管理

### 1.2 建设目标
对深基坑降水抽水泵进行台账维护、运行状态监测与故障查看，实现水泵设备的全生命周期管理，保障基坑降水作业安全高效运行。

### 1.3 使用角色
| 角色 | 职责 | 操作范围 |
|------|------|----------|
| 现场施工人员 | 查看水泵状态、处理故障告警 | 查看水泵数据、处理异常 |
| 安全管理员 | 监控整体水泵运行状况 | 全部水泵查看、故障处理 |
| 项目技术员 | 配置水泵、维护设备绑定 | 水泵维护、井点关联 |
| 项目经理 | 掌控项目水泵运行态势 | 查看统计概览、异常处理审核 |
| 系统管理员 | 系统配置与权限管理 | 全部功能及权限配置 |

### 1.4 业务价值
- 实时掌握抽水泵运行状态，降低设备故障风险
- 自动化故障预警，及时发现问题
- 设备台账管理，规范设备生命周期
- 运行时长统计，优化设备维护计划

### 1.5 功能定位
本模块属于"监测管理"二级菜单，是智慧工地平台安全生产管理子系统的核心监测模块，与水位监测、基坑维护、沉降位移监测共同构成完整的基坑监测体系。

## 二、业务流程设计

### 2.1 整体业务流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  水泵配置  │───→│  井点关联  │───→│  运行监测   │───→│  状态判断   │───→│  预警/故障  │
│ (新增/编辑) │    │ (两级级联) │    │ (实时数据)  │    │ (自动)    │    │  处理     │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └─────┬────┘
                                                                     │
                    ┌────────────────────────────────────────────────┤
                    │                                                │
              ┌─────▼─────┐                                  ┌─────▼─────┐
              │  正常运行   │                                  │  异常状态   │
              │ (持续监测)  │                                  │(故障/离线) │
              └───────────┘                                  └─────┬────┘
                                                                   │
                    ┌───────────────────────────────────────────────┤
                    │                                               │
              ┌─────▼─────┐                               ┌──────▼──────┐
              │  运行统计   │                               │  人工处理   │
              │ (时长统计)  │                               │ (故障维修)  │
              └───────────┘                               └──────┬──────┘
                                                                │
                                                         ┌─────▼─────┐
                                                         │  处理记录   │
                                                         │  归档      │
                                                         └───────────┘
```

### 2.2 业务输入
- 水泵基础配置数据（编号、名称、类型、厂家、型号、功率）
- 关联基坑和井点数据（两级级联选择）
- 水泵运行状态数据（运行/停止、在线/离线、故障/正常）
- 运行时长数据（今日运行、累计运行）
- 水位数据（当前水位、报警水位）

### 2.3 业务处理
- 两级级联选择：先选基坑，再选该基坑下的井点
- 状态判断：根据通信状态和故障状态综合判断设备状态
- 删除校验：检查是否绑定井点、是否有运行历史、是否有故障记录、是否有关联预警
- 预警关联：水泵故障/离线时自动触发预警

### 2.4 业务输出
- 水泵卡片列表（显示基坑、井点、运行时长、设备状态）
- 水泵详情（基本信息、运行状态）
- 删除确认弹窗（显示删除条件检查）
- 预警记录（关联到监测预警模块）

## 三、功能详细设计

### 3.1 搜索过滤栏

#### 3.1.1 功能说明
提供多条件搜索过滤功能，支持按编号、名称、关联井点、设备状态、运行状态筛选水泵。

#### 3.1.2 页面布局
- 单行水平排列，左侧为搜索条件，右侧为操作按钮
- 搜索条件：水泵编号/名称、关联井点、设备状态、运行状态
- 操作按钮：新增抽水泵、导出、查询、重置

#### 3.1.3 操作流程
1. 在输入框输入关键词或选择下拉条件
2. 点击"查询"按钮执行搜索
3. 点击"重置"清空所有搜索条件
4. 点击"新增抽水泵"打开新增弹窗
5. 点击"导出"导出当前数据

### 3.2 水泵卡片网格

#### 3.2.1 功能说明
以卡片形式展示每个水泵的基本信息和运行状态，支持快速浏览和操作。

#### 3.2.2 页面布局
- 四列网格布局，每行4张卡片
- 卡片根据状态使用不同边框颜色（故障-红色、离线-灰色、运行中-蓝色、停止-灰色）

#### 3.2.3 卡片结构
```
┌─────────────────────────────┐
│ [泵] PUMP001 1号抽水泵 [运行中]│ ← 卡片头部（图标、编号、名称、运行状态）
├─────────────────────────────┤
│ 📍 关联基坑: 翻车机房基坑     │ ← 字段列表
│ 📍 关联井点: JW001           │
│ ⏱️ 今日时长: 6.0h            │
│ 📊 设备状态: 正常             │
├─────────────────────────────┤
│    编辑      删除            │ ← 操作按钮
└─────────────────────────────┘
```

#### 3.2.4 按钮功能说明
| 按钮 | 功能 | 说明 |
|------|------|------|
| 编辑 | 打开编辑弹窗 | 修改水泵配置信息 |
| 删除 | 打开删除确认弹窗 | 验证删除条件后删除 |

### 3.3 水泵维护弹窗（新增/编辑/查看）

#### 3.3.1 功能说明
新增、编辑或查看水泵详细信息，包含基本信息和运行状态。

#### 3.3.2 页面布局
- 弹窗宽度：640px
- 查看模式：分为基本信息和运行状态两个部分
- 新增/编辑模式：表单字段排列

| 关联降水井 | 关联的井点编码 |
| 关联工点 | 关联的基坑名称 |
| 控制模式 | 远程控制/自动控制/现场手动 |

**运行状态**：
| 字段 | 说明 |
|------|------|

| 通信状态 | 在线/离线（标签显示） |
| 故障状态 | 正常/故障（标签显示） |
| 当前水位(m) | 当前水位值，超限标红 |

| 累计运行 | 累计运行时长 |

#### 3.3.4 新增/编辑模式字段
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 泵编号 | 文本输入 | 是 | 唯一标识，编辑时不可修改 |
| 泵名称 | 文本输入 | 是 | 中文名称 |
| 泵类型 | 下拉选择 | 是 | 潜水泵/深井泵/备用泵/排水泵/其他 |
| 关联基坑 | 下拉选择 | 是 | 两级级联第一步，选择后才可选择井点 |
| 关联井点 | 下拉选择 | 是 | 两级级联第二步，根据基坑过滤 |
| 井类型 | 只读文本 | - | 根据关联井点自动获取 |
| 通信状态 | 只读文本 | - | 在线/离线 |
| 运行状态 | 只读文本 | - | 运行中/已停止 |
| 故障状态 | 只读文本 | - | 正常/故障 |
| 今日运行时长 | 只读文本 | - | 自动统计 |
| 最新数据时间 | 只读文本 | - | 数据采集时间 |

#### 3.3.5 两级级联选择逻辑
| 步骤 | 操作 | 说明 |
|------|------|------|
| 第一步 | 选择基坑 | 从所有基坑中选择 |
| 第二步 | 选择井点 | 只显示该基坑下的降水井和坑内管井 |
| 联动 | 切换基坑 | 自动清空已选井点 |
| 禁用 | 未选基坑 | 井点下拉框禁用 |

### 3.4 删除确认弹窗

#### 3.4.1 功能说明
删除水泵前进行确认，显示删除条件检查结果。

#### 3.4.2 页面布局
- 弹窗宽度：480px
- 显示删除确认提示
- 显示4个删除条件检查结果
- 不满足条件时禁用删除按钮

#### 3.4.3 删除条件检查
| 条件 | 通过条件 | 不通过提示 |
|------|----------|------------|
| 未绑定井点 | well字段为空 | 已绑定井点，无法删除 |
| 没有运行历史 | totalDuration字段为空 | 存在运行历史，无法删除 |
| 没有故障记录 | fault字段为"正常" | 存在故障记录，无法删除 |
| 没有关联预警 | 预警列表中无该水泵 | 存在关联预警，无法删除 |

## 五、业务规则说明

### 5.1 数据校验规则

| 规则编号 | 校验内容 | 校验规则 | 异常处理 |
|----------|----------|----------|----------|
| V-01 | 水泵编号唯一性 | 不允许重复编码 | 新增时校验，提示"该编码已存在" |
| V-02 | 必填项校验 | 泵编号、名称、类型、基坑、井点必填 | 表单校验提示 |
| V-03 | 级联选择校验 | 必须先选择基坑才能选择井点 | 井点下拉框禁用 |
| V-04 | 水位值范围 | 0 ≤ 水位值 ≤ 100 | 超出范围标记为异常 |

### 5.2 状态流转规则

#### 5.2.1 设备状态判断规则
| 设备状态 | 判断条件 | 颜色标识 |
|----------|----------|----------|
| 正常 | 通信在线且故障状态正常 | 绿色 |
| 故障 | 故障状态为故障 | 红色 |
| 离线 | 通信状态为离线 | 灰色 |

#### 5.2.2 运行状态判断规则
| 运行状态 | 判断条件 | 颜色标识 |
|----------|----------|----------|
| 运行中 | status === "运行中" | 绿色 |
| 已停止 | status === "停止" | 灰色 |

#### 5.2.3 卡片边框颜色规则
| 状态组合 | 边框颜色 | 背景色 | 图标颜色 |
|----------|----------|--------|----------|
| 故障（无论运行状态） | border-red-200 | bg-red-50 | bg-red-100 text-red-600 |
| 离线（无论运行状态） | border-gray-300 | bg-gray-50 | bg-gray-100 text-gray-500 |
| 运行中且正常 | border-blue-100 | bg-blue-50 | bg-blue-100 text-blue-600 |
| 停止且正常 | border-gray-200 | bg-gray-50 | bg-blue-100 text-blue-600 |

### 5.3 删除规则

#### 5.3.1 删除条件（全部满足才可删除）
```
canDelete = !well && !totalDuration && fault === "正常" && !hasWarning
```

| 条件 | 说明 | 校验字段 |
|------|------|----------|
| 未绑定井点 | 水泵未关联任何井点 | well字段为空 |
| 无运行历史 | 水泵从未运行过 | totalDuration字段为空 |
| 无故障记录 | 水泵无故障记录 | fault字段为"正常" |
| 无关联预警 | 水泵无关联的预警记录 | 预警列表中无该水泵 |

#### 5.3.2 删除流程
1. 点击删除按钮打开确认弹窗
2. 显示4个删除条件检查结果
3. 不满足条件时禁用"确认删除"按钮
4. 满足所有条件时点击"确认删除"执行删除

### 5.4 级联选择规则

#### 5.4.1 基坑选项来源
```
workpointOptions = 从wellData中提取降水井和坑内管井的workpointName，去重后作为基坑选项
```

#### 5.4.2 井点选项过滤
```
filteredWells = 当选择基坑后，过滤出该基坑下的降水井和坑内管井
```

#### 5.4.3 编辑模式回填
```
当编辑模式打开时，根据水泵关联的井点编码查询井点信息，自动回填基坑和井点选择
```

### 5.5 自动触发规则
| 触发事件 | 触发条件 | 执行动作 |
|----------|----------|----------|
| 故障预警 | 故障状态变为"故障" | 推送预警到监测预警模块 |
| 离线预警 | 通信状态变为"离线"超过阈值时间 | 推送预警到监测预警模块 |
| 运行时长预警 | 连续运行超过设定阈值 | 推送预警到监测预警模块 |
| 大屏同步 | bigscreen=true的水泵 | 数据同步到大屏展示 |

## 六、业务逻辑关联

### 6.1 主数据关系

```
基坑维护（1）─────→（N）井点维护（1）─────→（1）抽水泵
     │                      │                    │
     │                      │                    ↓
     │                      │              水泵运行数据（N）
     │                      ↓
     │               水位监测数据（N）
```

### 6.2 父子级关系
| 父级 | 子级 | 关系说明 |
|------|------|----------|
| 基坑 | 井点 | 一个基坑包含多个井点 |
| 井点 | 抽水泵 | 一个井点可绑定一个抽水泵（观测井除外） |
| 抽水泵 | 运行数据 | 一个水泵产生多条运行记录 |

### 6.3 数据同步逻辑
| 同步方向 | 数据内容 | 同步方式 |
|----------|----------|----------|
| 基坑维护 → 抽水泵 | 基坑名称列表 | 级联选择时动态获取 |
| 水位监测 → 抽水泵 | 当前水位数据 | 传感器采集推送 |
| 抽水泵 → 监测预警 | 故障/离线预警 | 状态变化时自动推送 |
| 抽水泵 → 大屏展示 | 水泵状态数据 | bigscreen=true时同步 |

## 八、接口及数据交互

### 8.1 数据来源
| 数据 | 来源 | 获取方式 |
|------|------|----------|
| 水泵基础信息 | 水泵配置 | 接口查询 |
| 基坑列表 | 基坑维护模块 | 接口查询（级联选择） |
| 井点列表 | 水位监测模块 | 接口查询（级联选择） |
| 运行状态 | 设备状态采集 | 实时采集推送 |
| 水位数据 | 水位传感器 | 传感器采集推送 |
| 预警记录 | 监测预警模块 | 接口关联查询 |

### 8.2 接口调用关系

#### 8.2.1 水泵列表查询接口
```
GET /api/pump/pumps
参数:
  - code: 水泵编号/名称（模糊查询）
  - well: 关联井点（模糊查询）
  - status: 设备状态（正常/故障/离线）
  - runStatus: 运行状态（运行中/已停止）
  - page: 页码
  - pageSize: 每页条数
返回:
  - 水泵列表（含状态、运行时长、关联信息）
```

#### 8.2.2 水泵详情接口
```
GET /api/pump/pumps/{id}
返回:
  - 水泵基础信息
  - 运行状态（运行状态、通信状态、故障状态）
  - 运行时长（今日运行、累计运行）
  - 关联信息（井点、基坑）
```

#### 8.2.3 水泵维护接口
```
POST /api/pump/pumps        # 新增
PUT /api/pump/pumps/{id}    # 编辑
DELETE /api/pump/pumps/{id} # 删除
```

#### 8.2.4 基坑列表接口（级联选择）
```
GET /api/pump/workpoints
返回:
  - 基坑名称列表（已关联降水井或坑内管井的基坑）
```

#### 8.2.5 井点列表接口（级联选择）
```
GET /api/pump/wells?workpoint={workpointName}
参数:
  - workpoint: 基坑名称
返回:
  - 该基坑下的降水井和坑内管井列表
```

### 8.3 数据同步方式
| 同步场景 | 同步方式 | 说明 |
|----------|----------|------|
| 运行状态更新 | WebSocket推送 | 设备状态变化时实时推送 |
| 水位数据更新 | WebSocket推送 | 水位传感器采集后推送 |
| 预警推送 | 消息队列 | 故障/离线/时长预警推送到监测预警模块 |
| 大屏数据同步 | HTTP轮询 | 大屏端定时拉取数据 |
