# 水位监测管理需求说明书

---

## 一、功能概述

### 1.1 功能名称
水位监测管理

### 1.2 建设目标
对铁路工程施工基坑降水井水位进行实时监测、预警和抽水建议辅助，保障基坑施工安全，防止因水位超限导致的涌水、突泥等安全事故。

### 1.3 使用角色
| 角色 | 职责 | 操作范围 |
|------|------|----------|
| 现场施工人员 | 查看水位状态、处理异常预警 | 查看监测数据、处理异常 |
| 安全管理员 | 监控整体水位安全状况 | 全部井点查看、预警处理 |
| 项目技术员 | 配置井点基础参数、维护设备绑定 | 井点维护、传感器绑定 |
| 项目经理 | 掌控项目水位安全态势 | 查看统计概览、异常处理审核 |
| 系统管理员 | 系统配置与权限管理 | 全部功能及权限配置 |

### 1.4 业务价值
- 实时掌握基坑水位动态，降低安全事故风险
- 自动化预警机制，减少人工巡检成本
- 智能抽水建议，优化抽水设备调度
- 历史趋势追溯，为方案调整提供数据支撑

### 1.5 功能定位
本模块属于"监测管理"二级菜单，是智慧工地平台安全生产管理子系统的核心监测模块，与基坑维护、抽水泵管理、沉降位移监测共同构成完整的基坑监测体系。

## 二、业务流程设计

### 2.1 整体业务流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  基坑维护  │───→│  井点维护  │───→│ 传感器绑定 │───→│ 实时数据   │───→│  状态判断  │
│ (配置基坑) │    │(配置井点)  │    │(关联设备)  │    │  采集     │    │ (自动)    │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └─────┬────┘
                                                                     │
                    ┌────────────────────────────────────────────────┤
                    │                                                │
              ┌─────▼─────┐                                  ┌─────▼─────┐
              │  正常状态   │                                  │  异常状态   │
              │ (持续监测)  │                                  │(偏高/超限) │
              └───────────┘                                  └─────┬────┘
                                                                   │
                    ┌──────────────────────────┬───────────────────┤
                    │                          │                   │
              ┌─────▼─────┐           ┌──────▼──────┐     ┌──────▼──────┐
              │  预警通知   │           │  抽水建议    │     │  人工处理   │
              │ (自动触发)  │           │ (自动生成)   │     │ (填写记录)  │
              └───────────┘           └──────┬──────┘     └──────┬──────┘
                                             │                   │
                                       ┌─────▼─────┐       ┌─────▼─────┐
                                       │  水泵联动   │       │  处理记录   │
                                       │ (人工确认)  │       │  归档      │
                                       └───────────┘       └───────────┘
```

### 2.2 业务输入
- 基坑基础配置数据（基坑编码、名称、控制水位、报警水位）
- 井点配置数据（井点编码、名称、类型、深度、关联传感器）
- 传感器实时采集数据（当前水位值、采集时间、在线状态）
- 抽水泵运行状态数据（运行/停止/故障）

### 2.3 业务处理
- 根据当前水位与标准控制水位、报警水位比较，自动判断水位状态
- 根据井点类型、传感器状态、水位状态、水泵状态综合生成抽水建议
- 对偏高、超限状态自动触发预警，推送到监测预警模块
- 对数据异常（传感器离线、数据超时）进行标记和提示

### 2.4 业务输出
- 井点水位状态标签（正常/偏高/超限/数据异常）
- 抽水建议文本及判断依据
- 水位趋势图（近一天/近一周）
- 异常处理记录
- 大屏展示数据

### 3.2 搜索过滤栏

#### 3.2.1 功能说明
提供多条件搜索过滤功能，支持按编码、名称、基坑、状态、类型筛选井点。

#### 3.2.2 页面布局

## 五、业务规则说明

### 5.1 数据校验规则

| 规则编号 | 校验内容 | 校验规则 | 异常处理 |
|----------|----------|----------|----------|
| V-01 | 井点编码唯一性 | 不允许重复编码 | 新增时校验，提示"该编码已存在" |
| V-02 | 井点编码格式 | 字母+数字组合 | 输入校验，提示格式要求 |
| V-03 | 水位值范围 | 0 ≤ 水位值 ≤ 100 | 超出范围标记为数据异常 |
| V-04 | 标准控制水位 ＜ 报警水位 | 必须满足大小关系 | 保存时校验，提示"报警水位必须大于标准控制水位" |
| V-05 | 启用监测必填传感器 | enabled=true时sensor必填 | 表单校验提示 |
| V-06 | 井点深度正数 | depth ＞ 0 | 表单校验提示 |

### 5.2 状态流转规则

#### 5.2.1 水位状态判断规则
| 状态代码 | 状态名称 | 判断条件 | 颜色标识 |
|----------|----------|----------|----------|
| normal | 正常 | 当前水位 ≤ 标准控制水位 | 绿色 |
| high | 偏高 | 标准控制水位 ＜ 当前水位 ＜ 报警水位 | 橙色 |
| overlimit | 超限 | 当前水位 ≥ 报警水位 | 红色 |
| abnormal | 数据异常 | 传感器离线、数据超时、数据为空、数据越界或异常跳变 | 灰色 |

#### 5.2.2 状态判断优先级
```
数据异常 ＞ 超限 ＞ 偏高 ＞ 正常
```
当设备离线或监测数据异常时，即使最后一次水位数据达到报警阈值，也优先显示"数据异常"。

### 5.3 抽水建议计算规则

#### 5.3.1 建议生成前提条件
1. 井点类型支持抽水（降水井、坑内管井）
2. 已纳入水位监测（enabled=true）
3. 已绑定水位传感器
4. 已绑定抽水泵
5. 水位数据正常（非异常状态）
6. 水泵状态正常（非故障状态）

#### 5.3.2 建议结果说明
| 建议代码 | 建议名称 | 触发条件 | 颜色标识 |
|----------|----------|----------|----------|
| NO_PUMP | 暂无需抽水 | 水位正常且水泵停止 | 绿色 |
| START_PUMP | 建议启动水泵 | 水位偏高/超限且水泵停止 | 橙色 |
| URGENT_START | 建议尽快启动水泵 | 水位超限且水泵停止 | 红色 |
| CONTINUE_PUMP | 建议继续抽水 | 水位偏高/超限且水泵运行中 | 橙色 |
| STOP_PUMP | 建议停止水泵 | 水位正常且水泵运行中 | 蓝绿色 |
| CHECK_ON_SITE | 建议现场检查 | 水泵故障、传感器离线、数据异常 | 红色 |
| UNABLE_TO_GENERATE | 暂无法生成建议 | 未绑定水泵或传感器 | 灰色 |
| OBSERVATION_ONLY | 观测井不生成建议 | 井点类型为观测井 | 灰色 |

#### 5.3.3 建议判断优先级
```
设备或数据异常 ＞ 抽水无效 ＞ 建议尽快启动 ＞ 建议启动 ＞ 建议继续 ＞ 建议停止 ＞ 暂无需抽水
```

#### 5.3.4 观测井特殊规则
- 观测井只监测水位，不生成抽水建议
- 可以：展示实时水位、展示水位趋势、产生水位预警
- 不可以：绑定抽水泵、生成启动/继续/停止水泵建议

### 5.4 水位趋势计算规则
| 趋势代码 | 趋势名称 | 计算规则 |
|----------|----------|----------|
| RISING | 上升 | trendValue ≥ 0.05m |
| FALLING | 下降 | trendValue ≤ -0.05m |
| STABLE | 平稳 | -0.05m ＜ trendValue ＜ 0.05m |
| NO_DATA | 暂无数据 | 有效数据少于3条或传感器离线 |

> trendValue = 最新有效水位 - 30分钟前有效水位

### 5.5 自动触发规则
| 触发事件 | 触发条件 | 执行动作 |
|----------|----------|----------|
| 预警生成 | 水位状态变为偏高或超限 | 推送预警到监测预警模块 |
| 建议重算 | 最新水位/趋势/水泵状态/传感器状态/水位阈值/设备绑定关系变化 | 后台重新计算抽水建议 |
| 大屏同步 | bigscreen=true的井点 | 数据同步到大屏展示 |

### 5.6 数据新增、修改、删除规则

| 操作 | 规则说明 |
|------|----------|
| 新增井点 | 编码唯一性校验；选择基坑后自动带出控制水位和报警水位；可手动修改水位阈值 |
| 编辑井点 | 编码不可修改；修改基坑时自动更新水位阈值；可修改传感器绑定 |
| 删除井点 | 已绑定传感器、已绑定抽水泵、有历史采集数据的井点不允许删除 |

### 5.7 异常处理规则
| 异常场景 | 处理方式 |
|----------|----------|
| 传感器离线 | 状态标记为"数据异常"，生成"建议现场检查"建议 |
| 数据超时 | 状态标记为"数据异常"，提示最后采集时间 |
| 水泵故障 | 生成"建议现场检查"建议，显示故障水泵信息 |
| 水位值越界 | 状态标记为"数据异常"，不参与预警判断 |

## 六、业务逻辑关联

### 6.1 主数据关系

```
基坑维护（1）─────→（N）井点维护（1）─────→（1）水位传感器
     │                      │
     │                      │
     │                      ↓
     │               井点监测数据（N）
     │
     ↓
 基坑水位阈值 ──→ 井点状态判断
```

### 6.2 父子级关系
| 父级 | 子级 | 关系说明 |
|------|------|----------|
| 基坑 | 井点 | 一个基坑包含多个井点，井点继承基坑水位阈值 |
| 井点 | 监测数据 | 一个井点产生多条监测数据记录 |
| 井点 | 水位传感器 | 一个井点绑定一个水位传感器 |
| 井点 | 抽水泵 | 一个井点可绑定一个抽水泵（观测井除外） |

### 6.3 多对多关系
- 井点与预警记录：一个井点可产生多条预警记录，一条预警记录对应一个井点
- 井点与大屏展示：多个井点可同步到同一大屏

### 6.4 数据同步逻辑
| 同步方向 | 数据内容 | 同步方式 |
|----------|----------|----------|
| 基坑维护 → 井点维护 | 控制水位、报警水位 | 选择基坑时自动带出 |
| 传感器 → 井点监测 | 当前水位、采集时间、在线状态 | 实时采集推送 |
| 井点 → 抽水泵管理 | 井点编码关联 | 通过well字段关联 |
| 井点 → 监测预警 | 预警记录 | 状态变化时自动推送 |
| 井点 → 大屏展示 | 水位数据、状态标签 | bigscreen=true时同步 |

## 八、接口及数据交互

### 8.1 数据来源
| 数据 | 来源 | 获取方式 |
|------|------|----------|
| 井点基础信息 | 井点维护配置 | 接口查询 |
| 基坑水位阈值 | 基坑维护模块 | 接口关联查询 |
| 实时水位数据 | 水位传感器（通过DTU采集箱） | MQTT/Modbus协议采集 |
| 传感器状态 | 设备管理模块 | 接口查询 |
| 抽水泵状态 | 抽水泵管理模块 | 接口关联查询 |
| 水位趋势 | 后台计算 | 接口返回 |

### 8.2 接口调用关系

#### 8.2.1 井点列表查询接口
```
GET /api/water-level/wells
参数:
  - code: 井点编码（模糊查询）
  - name: 井点名称（模糊查询）
  - workpointName: 基坑名称（模糊查询）
  - dataStatus: 预警状态
  - wellType: 井点类型
  - page: 页码
  - pageSize: 每页条数
返回:
  - 井点列表（含实时数据、状态、传感器状态）
  - 统计汇总（总数、正常数、异常数）
```

#### 8.2.2 井点详情接口
```
GET /api/water-level/wells/{id}
返回:
  - 井点基础信息
  - 实时监测数据
  - 抽水建议（suggestionCode, suggestionName, reasonText, generatedTime）
  - 水位趋势（trendCode, trendName, trendValue, trendPeriod）
  - 关联水泵信息
```

#### 8.2.3 历史趋势接口
```
GET /api/water-level/wells/{id}/trend
参数:
  - period: realtime/day/week
返回:
  - 历史水位数据列表（时间戳、水位值、状态）
  - 水泵运行时段标记
```

#### 8.2.4 井点维护接口
```
POST /api/water-level/wells        # 新增
PUT /api/water-level/wells/{id}    # 编辑
DELETE /api/water-level/wells/{id} # 删除
```

#### 8.2.5 异常处理接口
```
POST /api/water-level/wells/{id}/handle
参数:
  - handlePerson: 处理人
  - handleDesc: 处理说明
```

### 8.3 数据同步方式
| 同步场景 | 同步方式 | 说明 |
|----------|----------|------|
| 实时水位数据 | WebSocket推送 | 传感器采集后实时推送到前端 |
| 井点状态变化 | 实时计算 | 后台根据最新数据实时计算状态 |
| 预警推送 | 消息队列 | 状态变化时推送到监测预警模块 |
| 大屏数据同步 | HTTP轮询 | 大屏端定时拉取数据 |

### 8.4 参数要求
| 参数 | 类型 | 要求 |
|------|------|------|
| 井点编码 | string | 字母+数字，最大20字符 |
| 水位值 | number | 保留两位小数，单位米 |
| 采集时间 | string | 格式 YYYY-MM-DD HH:mm:ss |
| 趋势计算周期 | number | 默认30分钟 |
| 数据超时阈值 | number | 默认2小时 |
